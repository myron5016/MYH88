# 真实证券 Logo 架构设计

## 目标

让持仓地图和持仓表格为当前及以后新增的证券显示真实公司或证券 Logo，绝不再把手绘近似图当作真实 Logo 展示。

## 当前问题

客户端目前使用硬编码的“股票代码 → 本地 SVG”映射、另一张硬编码的“股票代码 → 公司域名”映射，以及股票代码首字母作为兜底。部分本地 SVG 只是近似图；任何不在映射表中的新代码也无法自动解析。网站 favicon 同样不能证明图片就是对应证券的真实 Logo。

## 产品规则

1. 只有来自可信行情资料接口或经过人工核验的例外配置，才允许显示为 Logo。
2. 如果无法获得可信 Logo，就显示股票代码缩写，不生成或猜测 Logo。
3. ETF 优先使用基金产品自身经过核验的 Logo；不得悄悄用发行商 Logo 代替。
4. `CASH` 是应用内概念而非上市证券，继续使用明确标识的本地应用图标。
5. 新增持仓可自动解析，无需为每只股票重新部署代码。

## 推荐架构

### Worker 元数据接口

在现有 Cloudflare Worker 中新增 `GET /logos?symbols=AAPL,NVDA`。接口复用行情接口的代码规范化与校验逻辑，限制单次代码数量，再使用服务端的 `FINNHUB_API_KEY` 查询 Finnhub 公司资料。

JSON 响应按股票代码返回记录：

```json
{
  "logos": {
    "NVDA": {
      "status": "verified",
      "path": "/logo/NVDA",
      "name": "NVIDIA Corp",
      "source": "finnhub"
    },
    "MSTU": {
      "status": "missing"
    }
  }
}
```

成功的资料结果在 `MYH88_CACHE` 中保存 30 天；未找到的结果保存 24 小时，避免不支持的代码在每次打开页面时重复消耗接口额度。

### Worker 图片代理

新增 `GET /logo/:symbol`。该接口只读取元数据接口已经解析并缓存的 Logo 地址，由服务端获取图片；返回之前校验 HTTPS 地址、图片内容类型、请求成功状态和保守的文件大小上限，再通过浏览器及边缘缓存长期缓存图片。

客户端不能传入任意上游图片地址。这样既不会把接口变成开放代理，也不会暴露行情接口密钥。

### 已核验例外配置

在服务端保留一份很小的例外配置表，用于处理行情提供商缺失或证券代码存在歧义的情况。每条记录都必须指向基金产品或公司的官方资源，并附带简短来源说明。例外配置只处理少数特殊情况，不能成为主要解析方式。

现有近似 SVG 不再作为公司 Logo 使用。Logo 目录中只保留 `CASH` 所需的应用图标。

### 前端解析流程

页面渲染时先立即显示股票代码缩写，保证布局稳定。前端把所有非现金持仓代码合并为一次 `/logos` 请求，把成功结果保存在内存映射中；元数据返回后只更新 Logo 元素，不重新绘制整个页面。

持仓地图和持仓表格共用同一个解析器。图片加载失败时，该元素永久切回代码缩写。新增持仓在下一次渲染时会自动加入查询。

## 失败与更新策略

- Worker 或行情提供商不可用：继续显示代码缩写，投资组合的其他功能正常工作。
- 未知或不支持的代码：缓存 `missing` 状态并显示代码缩写。
- 上游地址无效或返回的不是图片：拒绝该结果并显示代码缩写。
- 提供商后来补充 Logo：24 小时的失败缓存到期后自动重试。
- 提供商更新 Logo：30 天的元数据缓存和图片缓存到期后自动刷新，无需部署。

## 安全与隐私

- `FINNHUB_API_KEY` 只保存在 Worker 环境中。
- 规范化证券代码并限制单次批量数量。
- 图片代理只允许访问可信提供商返回的地址或经过审核的例外地址。
- 强制使用 HTTPS，并验证响应类型及文件大小。
- 转义所有证券代码和名称，不插入提供商返回的 HTML。

## 测试

- 为代码规范化、批量限制、成功及失败缓存、ETF 回退、非法 URL、错误内容类型、超大图片和提供商故障编写单元测试。
- 为 `/logos` 和 `/logo/:symbol` 编写 Worker 路由测试。
- 为批量请求、真实图片渲染、`CASH`、未知代码和图片加载失败回退编写前端测试。
- 在桌面端和移动端使用当前持仓及一个全新未知代码进行浏览器人工验证。

## 上线顺序

先部署 Worker 接口，再部署前端解析器。上线过程中界面默认从股票代码缩写开始，因此始终有安全回退。生产环境验证新接口后，再移除旧的手工公司 SVG 映射。
