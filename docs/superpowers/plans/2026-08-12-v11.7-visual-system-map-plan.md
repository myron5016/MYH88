- Modify `brand-v11.7.css`.

**Implementation:**

- Preserve `squarifiedTreemap`, `treemapItems`, `treemapHeight`, tile coordinates, tile width and tile height.
- Preserve the rule that tile area is driven by cost value.
- Add stable data attributes such as `data-symbol`, `data-sector` and `data-tile-size`.
- Add `tabIndex` only to visible tiles and expose a complete `aria-label` containing symbol, value and weight.
- Keep real local Logo assets first, then remote favicon fallback, then clean code fallback.

  - medium: Logo, symbol and compact value/weight;
  - small: Logo, symbol and weight;
  - micro: Logo or symbol only, with full details in title and aria label.
- Ensure a newly added symbol never causes its label to expand the tile.
- Keep sector bar and legend colors aligned with the same sector color family.

**Verification:**

- Keep the existing 1, 5, 10, 16, 20 and 30 asset desktop treemap tests.
- Keep the existing 1, 5, 10, 20 and 30 asset mobile treemap tests.
