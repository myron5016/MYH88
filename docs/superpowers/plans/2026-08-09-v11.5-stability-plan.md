# V11.5 Stability Patch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reject stale static quotes and make initial data loading render-first without changing holdings, ledger schema, provider routing, or manual FX behavior.

**Architecture:** Add pure quote-cache parsing/freshness and background-task scheduling helpers to `myh88-core.js`, then use them from the existing split browser scripts. Static fallback remains the last resort, but it fails closed when its quote date is more than two completed US sessions behind the current completed session. Initial loading renders shared/local data first and schedules the snapshot and quote refresh independently.

**Tech Stack:** Browser JavaScript, shared `myh88-core.js` global API, Node `node:test`, existing `npm test` release validator.

## Global Constraints

- Do not modify `data.json`, `backups/`, transactions, positions, or DCA records.
- Preserve manual FX mode, Twelve/Finnhub routing, last-close mode, service-worker behavior, and existing UI labels.
- Static quotes are accepted only when no more than 2 completed US trading sessions behind the supplied reference date.
- A stale or malformed static cache must not overwrite an existing in-memory/local price.
- No new dependencies.

```js
import test from "node:test";
import assert from "node:assert/strict";

await import("../myh88-core.js");
const { parseStaticQuoteCache, isStaticQuoteFresh, scheduleBackgroundTasks } = globalThis.MYH88Core;

const holidays = { "2026-07-03": "Independence Day observed" };
const quote = (date) => ({
  cachedAt: Date.parse(`${date}T21:00:00Z`),
  body: JSON.stringify({ NVDA: { symbol: "NVDA", close: "200", datetime: `${date} 16:00:00` } }),
});

test("accepts a well-formed static quote within two completed sessions", () => {
  const parsed = parseStaticQuoteCache(quote("2026-07-02"));
  assert.equal(parsed.asOfDate, "2026-07-02");
  assert.equal(isStaticQuoteFresh(parsed, "2026-07-07", holidays, 2), true);
});

test("rejects a static quote older than two completed sessions", () => {
  const parsed = parseStaticQuoteCache(quote("2026-07-02"));
  assert.equal(isStaticQuoteFresh(parsed, "2026-07-08", holidays, 2), false);
});

test("rejects malformed static cache data", () => {
  assert.equal(parseStaticQuoteCache({ cachedAt: Date.now(), body: "not-json" }), null);
  assert.equal(isStaticQuoteFresh(null, "2026-08-09", {}, 2), false);
});

test("background tasks start independently instead of waiting on the snapshot", async () => {
  let releaseSnapshot;
  const snapshot = new Promise((resolve) => { releaseSnapshot = resolve; });
  let refreshStarted = false;
  const errors = [];
  const tasks = scheduleBackgroundTasks([
    { label: "opening snapshot", task: () => snapshot },
    { label: "price refresh", task: () => { refreshStarted = true; } },
  ], (error, label) => errors.push(`${label}:${error.message}`));
  await Promise.resolve();
  assert.equal(refreshStarted, true);
  releaseSnapshot();
  await Promise.all(tasks);
  assert.deepEqual(errors, []);
});
```

### Task 2: Implement pure stability helpers

**Files:**
- Modify: `myh88-core.js` near the existing quote/date helpers and exported `MYH88Core` object.
- Test: `tests/stability.test.mjs`

**Interfaces:**
- `parseStaticQuoteCache(value)` returns `{ quotes, cachedAt, asOfDate, quoteDates }` or `null`.
- `isStaticQuoteFresh(value, referenceDate, holidays, maxSessions)` returns a boolean.
- `scheduleBackgroundTasks(tasks, onError)` returns an array of promises and starts every task independently.

- [x] **Step 1: Implement date parsing and trading-session distance**

Use the first `YYYY-MM-DD` or `YYYY/MM/DD` date in `datetime`, `date`, `asOf`, or a numeric timestamp. Count only weekdays not present in `holidays` between the quote date and reference date. Reject future quote dates and malformed/no-date values.

- [x] **Step 2: Implement static cache parsing**

Parse the outer JSON string/object, parse `body` when it is a JSON string, require at least one quote object, and use the oldest quote date as `asOfDate` so a mixed cache cannot hide its stalest symbol.

- [x] **Step 3: Implement independent background scheduling**

Normalize each task to `{ label, task }`, schedule each with `Promise.resolve().then(task)`, catch errors without rejecting the returned task promise, and report through `onError(error, label)`.
