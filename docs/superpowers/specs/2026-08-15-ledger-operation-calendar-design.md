# 账本操作日历设计

## 目标

将公开账本的默认页从重复账户 KPI 的“账本总览”替换为“操作日历”。顶部资金 KPI 继续承担账户当前状态的展示；账本承担交易发生时间和操作节奏的复盘。该改动不改变持仓、行情、成本、收益率、管理员权限或云端同步逻辑。

## 信息结构

### 资金总览标题

现有页面顶部七项 KPI 上方增加统一标题“资金总览”和简短说明“本金、资产与盈亏的实时概览”。标题与“梦想金库账本”“个股收益率曲线”采用同一层级的版式，但不重复显示额外 KPI。

### 账本默认页：操作日历

公开账本的第一页名称改为“操作日历”。页面显示当前选中月份的月历：

- 顶部有上月、当前月份、下月按钮；未来月份不可进入。
- 每个日期格聚合当天未作废的买入、卖出、追加本金和提取本金。
- 日期格最多显示两条关键事件；其余事件以“另 N 笔”提示，不产生空白占位。
- 买入和提取使用资金流出色，卖出和追加本金使用资金流入色。颜色表达现金方向，不表达证券涨跌。
- 点击有记录的日期格，在日历下方展开该日的完整事件清单，含类型、代码或本金说明、金额、备注；再次点击或选择其他日期切换内容。
- 无事件月份显示简洁空状态和月份切换，不显示虚构统计。

日历只基于 `state.transactions` 与 `state.cashFlows`，不读取行情服务，不改变交易数据。买入按成交总额与手续费合并为现金流出；卖出按成交净额合并为现金流入；本金流水使用原始 USD 金额。

### 账本切换和手势

账本公开页面仍有两个入口：`操作日历` 和 `交易流水`。管理员保持额外的批次管理、资金流水与备份页面。

- 顶部文字页签是主切换入口，取消视觉上像空白框的页码点。
- 桌面端在页签右侧保留紧凑的上一页、下一页图标按钮，只在可切换时启用。
- 在整个账本内容区的空白区域、日历和摘要区域支持左/右滑；输入框、按钮、弹窗及横向滚动表格不拦截原有手势。
- 移动端日历保持完整周结构，可横向滑动切换页面；点击日期仍可查看当天明细。
- 键盘左右方向键继续可用，焦点位于输入框或表格控件时不触发切换。

## 长期定投专区

长期定投区域的桌面与移动布局均调整为：`VOO 名片 -> QQQM 名片 -> 当月定投计划`。定投计划不再作为左侧首卡。定投成本、市值、收益率和历史记录保持现有逻辑。

## 权限与兼容性

- 非管理员只看到操作日历和交易流水，且无任何买入、卖出、编辑、作废或备份控制。
- 管理员可继续使用原有账本管理页面和交易录入入口。
- 旧的账本总览 DOM 标识将被替换或迁移，测试更新为验证日历渲染、月份切换、事件聚合、点击展开、全区手势以及非管理员权限边界。
- 保留现有数据文件格式，旧交易记录与本金流水无需迁移。

## 验证

1. 单元测试覆盖同日多笔交易聚合、买卖/本金流水金额方向、无记录月份、月份边界和未来月份禁用。
2. 手势测试覆盖日历空白区滑动、日期格滑动、横向表格与输入控件不误触。
3. 桌面和移动截图检查标题、日历六周布局、展开面板、页签与定投排序。
4. 执行完整发布校验与现有测试，确认行情代理和账本数据未被改动。
