# 做空与买入平空

用户已确认不自动拆分跨零交易，并授权完成测试后直接上线。

## 架构设计

- 新增 `short`（卖出开空）和 `cover`（买入平空），录入数量始终为正数。普通买入和卖出维持多头语义。
- 批次记录正数量与方向；汇总空头持仓为负股数、负成本基数。开空批次基数是扣除手续费后的开空净收入。
- 现金 = 本金 + 已实现盈亏 − 带符号成本；净资产 = 现金 + 带符号市值。平空盈亏 = 分配的开空净收入 − 平空金额 − 平空手续费。
- 平空默认 FIFO，可指定批次；超量平仓、反向开仓均拒绝。先平仓，再独立开反向仓位。
- 历史回放、当前持仓和预览共用批次计算；迁移期初日前旧记录保持历史口径。
- 地图按绝对成本与现金显示，标注空头；持仓占比按绝对市值计算，净资产仍使用带符号市值。
- 本功能是成交记账，不模拟券商保证金和借券额度。实际借券费用不自动推算。
